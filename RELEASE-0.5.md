# Обитель Мёртвых 0.5

- Исправлен адрес API Cloudflare: запросы идут в `/api/`.
- Убрана повторная загрузка VK Bridge через внешний CDN перед `<head>`.
- Компактная навигация, карточки районов, экран кланов; адаптация боя и прокручиваемой паузы к низкому экрану телефона.
- Восемь районов. Новые: метро, промзона и порт; отдельные процедурные фоны и портреты боссов.
- Машинист: 3900 HP, 10% брони, 35 секунд между атаками. Плавильщик: 4700 HP, 20%, 45 секунд. Адмирал: 6200 HP, 5%, 50 секунд.
- Старые сохранения расширяются до восьми районов без сброса прогресса.
- Серверные кланы: создание со второго уровня, заявки с принятием главой, до 20 участников, выход и передача лидерства, рейды участников. Сессии не публикуются.

## Обновление

Клиент в корне репозитория содержит готовый `game-boot.js`. Для обновления кланов и новых правил боссов **также требуется публикация обновлённого Cloudflare Worker**: `npm run deploy:worker` в авторизованном аккаунте с существующей базой из `wrangler.jsonc`. Дополнительной миграции SQL не требуется: кланы сохраняются в текущем документе `game_world`.

Публикация кода в GitHub сама по себе не подтверждает обновление Worker. Проверка в браузере проводилась локально; запуск в настоящем приложении ВК требует проверки на устройстве.
