# Обитель Мёртвых · бета 0.4

Пиксельная игра: энергия → зачистки → снаряжение → совместный рейд → следующий район.

## Запуск

Node.js 24: `node server.mjs`, открыть http://127.0.0.1:4173/.
Тесты: `node --test tests/*.test.mjs`.
Сборка хостинга: `pnpm install --frozen-lockfile`, `pnpm build`, `node package-beta.mjs`.

## Что работает

- Пять районов, три волны в каждом. После волны камера продвигается дальше.
- Автоогонь, WASD/стрелки/мобильный джойстик. Shift/пробел/правая кнопка — бег с выносливостью.
- Пистолет, карабин, дробовик; экипировка видна на герое. Внешность героя сохранена.
- Четыре комплекта одежды/брони. Чертежи открываются по уровню **или** числу побед над боссами. Для создания нужны детали, ткань и ядра. Купленные комплекты можно менять бесплатно.
- Инвентарь с иллюстрациями материалов и рецептов. Ткань выдаётся за успешные зачистки и боссов.
- 60 энергии, зачистка 8, атака босса 12; восстановление 1/5 минут.
- До босса нужны 3 зачистки. До 10 участников в рейде, каждый атакует в своё время. Общее здоровье и награды рассчитывает сервер; повторная атака через 45 секунд.
- Первый новый уровень после четырёх успешных зачисток первого района; дальше опыт растёт по квадратичной кривой.
- Гараж, ежедневный контракт, настройки управления и контраста, новый логотип.

## Хранение и публикация

Локально — `.data/world.json`. В размещённой бете — D1, таблица `game_world`. Проверка ревизии и повтор транзакции предотвращают потерю одновременного урона и ресурсов. Схема/миграции в `db/` и `drizzle/`. В браузере гостевая HttpOnly cookie; игровая экономика хранится на сервере. Не очищайте cookie, если хотите сохранить гостевой профиль. Перенос между устройствами пока не подключён.

GitHub хранит исходники. GitHub Pages не выполняет Node/Worker API: для онлайн-беты нужен серверный хостинг. `.openai/hosting.json` связывает проект с размещением, без секретов. Изменения отправляются в `main`.

## Ограничения беты

Это браузерная бета, а не утверждённый релиз ВК. VK ID, список друзей, платежи и реклама не подключены. Для привязки к ВК нужен ID приложения и настройка кабинета. Секреты нельзя публиковать в исходниках.

Обычный бой сообщает результат клиентом: сервер проверяет билет, время и пределы награды, но полной защиты от читов ещё нет. Боссы используют общий спрайт, а атака рейда рассчитывается кнопкой. Анимация ног — программный риг. Хранилище одной ревизии рассчитано на небольшую бету; перед массовым запуском нужны раздельные записи игроков/рейдов и нагрузочные тесты. Платежей нет.

Графика создана image_gen. Исходники в `assets/`, промпты — `assets/PROMPTS.json` и `assets/BETA-PROMPTS.md`. Спрайты с магентой компонуются в Canvas без изменения исходного файла.
