# Обитель Мёртвых · 0.2

Запуск: `node server.mjs`, затем http://127.0.0.1:4173. Сервер доступен только на этом компьютере. Тесты: `node --test tests/*.test.mjs`.

## Игровой цикл

Энергия → зачистка района (3 волны без босса) → детали и опыт → оружие, броня, машина → отдельный асинхронный рейд на босса → следующий район.

- 5 районов с новыми детальными растровыми фонами.
- Детальные пиксельные спрайты: герой в двух позах, ходок, бегун, громила, босс. Полного набора анимаций пока нет; пять боссов пока используют общий спрайт.
- WASD / стрелки или мобильный джойстик; автоогонь; пробел / правая кнопка — рывок.
- 60 энергии, зачистка стоит 8, атака босса 12; +1 каждые 5 минут по серверному времени.
- Босс доступен после 3 успешных зачисток и рекомендуемого уровня.
- Создание рейда, ссылка приглашения, до 10 гостевых участников; каждый атакует в своё время, HP босса общее.
- Атака рейд-босса сейчас рассчитывается кнопкой на сервере по экипировке, без отдельной интерактивной боевой сцены. Перезарядка 45 секунд.
- Прогресс, энергия, магазин, рейды и выдача наград хранятся на сервере в .data/world.json. Гостевая сессия — HttpOnly cookie.

## Ограничения

Это локальный прототип онлайн-механики, не опубликованная игра ВК. Ссылка на рейд работает только там, где доступен этот сервер. Для игры с друзьями из интернета нужны HTTPS-хостинг, VK ID/проверка параметров запуска, привязка гостевых профилей и интеграция друзей.

Результаты обычной зачистки пока сообщаются клиентом с ограничением по билету, времени и максимальным наградам. Это не полноценная защита от читов. Урон рейда и энергия рассчитываются сервером. Хранилище JSON рассчитано на один процесс; до масштабирования нужны БД и транзакции. Нет реальных платежей, рекламы и VK Bridge. Секрет ВК не используется.

Графика создана встроенным image_gen; исходники — assets/district-0.png … district-4.png и assets/characters.png. Полные промпты — assets/PROMPTS.json. Магентовый фон спрайтов исключается при игровом композитинге; исходное изображение не меняется. Фоны пока загружаются все сразу; перед публикацией нужны оптимизация веса и поэтапная загрузка.

## Проверено

7 автоматических тестов: прогрессия, энергия, улучшения, два независимых участника рейда, общее HP, перезагрузка серверного состояния, перезарядка, одноразовая награда, повторное сохранение результата без удвоения. В браузере: главный экран, мобильный экран 390×844, начало зачистки со списанием энергии, пауза и сохранение отступления.
